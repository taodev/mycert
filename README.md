# 自签 SSL 证书指南

## 📥 安装根证书

下载并安装根证书：[📄 dev-ca.crt](cert/dev-ca.crt)

---

### 🪟 Windows

- 下载 `dev-ca.crt`
- 双击打开，点击“安装证书”
- 选择「本地计算机」
- 存储位置选择「受信任的根证书颁发机构」
- 完成安装后重启浏览器

---

### 🐧 Linux

> 各发行版方法不同，以下为常见路径示例（需 `sudo` 权限）：

```bash
# 复制证书
sudo cp dev-ca.crt /usr/local/share/ca-certificates/dev-ca.crt

# 更新系统信任
sudo update-ca-certificates
```

---

### 📱 iOS 安装说明与常见问题

> iOS 安装自签证书稍有复杂，请务必按以下步骤操作：

#### 安装步骤

1. 使用 **Safari 浏览器** 打开本页面并下载 `dev-ca.crt`
2. 打开 `设置 > 通用 > VPN 与设备管理 > DEV-CA > 安装`
3. 进入 `设置 > 通用 > 关于本机 > 证书信任设置`，点击「信任」

#### 常见问题与排查

- ⚠️ **证书未完全信任**  
  安装后需手动设置为“完全信任”  
  路径：`设置 > 通用 > 关于本机 > 证书信任设置`

- 📎 **证书链不完整**  
  服务端应返回完整证书链（包括中间证书）

- 🔐 **证书不匹配**  
  服务端使用的证书必须由当前 CA 签发

- ⏳ **证书已过期/无效**  
  请确认签发时间与有效期设置是否正确

- 🔧 **TLS 配置问题**  
  推荐使用 `TLS 1.2` 或 `TLS 1.3`，禁用 `SSLv3` 等旧协议
